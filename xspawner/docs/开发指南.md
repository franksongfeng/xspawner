### 库依赖

xspawner及其插件所依赖的主要python库（及其版本）：

- tornado, 6.4.1
- pywebio, 1.8.3
- pycurl，7.45.7
- psutil, 5.9.5
- bokeh, 3.1.1
- tortoise-orm, 0.23.0
- aiomysql, 0.2.0
- asyncpg, 0.30.0
- pyinstaller, 6.22.3

### 禁用

避免直接使用以下Python库：

- pywebio_battery
- redis
- aiohttp
- fastapi
- flask
- django

异步编程使用tornado库，避免直接引用asyncio模块

并发编程使用协程，避免直接使用多线程

前端实现基于pywebio，尽可能减少使用javascript和css

pywebio 的会话模式采用协程模式

# XSpawner 指南

**XSpawner** 是一个轻量级的 Python Web 管理平台，旨在帮助开发者快速构建小型但功能完整的异步 Web 服务。它将 **Tornado** 的高性能异步能力与 **PyWebIO** 的快速 UI 组件相结合，显著简化了现代 Web 应用的开发流程，尤其适合熟悉 Python 并希望避免前后端分离复杂性的开发者。

------

## 一、核心功能

XSpawner 提供了以下关键特性：

- **🐍 全 Python 技术栈**：前端和后端均使用纯 Python 开发，无需切换语言或框架。
- **📦 类即服务（Class as a Service, CaaS）**：每个服务都被封装为一个独立的类，便于复用和管理。
- **🌐 简单的生命周期管理**：通过依赖关系管理服务的创建、启动和停止等生命周期操作。
- **⚡ 异步编程**：基于 Tornado 久经考验的协程能力，提供高性能的异步处理。
- **🗄️ 数据库支持**：基于 Tortoise ORM，支持 SQLite、MySQL 和 PostgreSQL，并内置数据库备份与清理功能。
- **🔒 安全增强**：原生支持 SSL/TLS 证书，保障通信安全。

------

## 二、用途与适用场景

XSpawner 适合以下场景：

- **快速原型开发**：需要快速搭建一个带有 UI 的异步 Web 服务，验证想法。
- **小型管理平台**：构建轻量级的后台管理工具或内部服务。
- **微服务/服务编排**：利用“类即服务”和生命周期管理能力，组织多个独立服务。
- **异步任务处理**：需要利用 Tornado 协程处理高并发或异步任务的场景。

------

## 三、结构

XSpawner 的项目结构清晰，采用模块化设计：

- **核心模块**（`xspawner.py`、`service.py`、`orm.py`、`log.py`、`constants.py`）位于主包根目录。
- **插件系统**（`plugins/`）支持 从`Spawner`派生插件类。`administrator`等插件可独立包含测试和静态资源。
- **示例代码**（`demo/`）覆盖多种使用场景的例程，便于快速上手。
- **根目录脚本**（`init`、`start`、`stop`、`backup`、`drop`）提供命令行管理接口。

主程序包内部按功能划分了多个子目录和模块。

| 名称             | 类型 | 说明                       |
| :--------------- | :--- | :------------------------- |
| `demo/`          | 目录 | 示例代码目录               	|
| `plugins/`       | 目录 | 插件目录					 |
| `plugins/administrator`	| 目录 | 核心插件 - 管理员	|
| `static/`        | 目录 | 静态文件目录               |
| `__init__.py`    | 文件 | 包初始化               	|
| `__main__.py`    | 文件 | 程序入口               	|
| `__version__.py` | 文件 | 版本信息               	|
| `constants.py`   | 文件 | 常量定义               	|
| `log.py`   	   | 文件 | 日志接口               	|
| `client.py`      | 文件 | web客户端              	|
| `misc.py`        | 文件 | 杂项基础函数               |
| `orm.py`         | 文件 | SQL应用接口及对象关系映射    |
| `service.py`     | 文件 | 系统服务管理核心           |
| `xspawner.py`    | 文件 | 异步Web请求处理和插件基类    |
